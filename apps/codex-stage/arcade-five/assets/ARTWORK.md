# Arcade Five: Artwork

Five original environment images created with the built-in image_gen tool on 2026-10-02. PNG originals are preserved without editing. Gameplay pieces, shadows, animation and feedback are original Canvas drawings driven by the physics state. Audio is synthesized with Web Audio, not sampled from commercial games.

These project assets are distributed under Apache-2.0, without asserting exclusive copyright in AI-generated material. Existing Lucide icons retain their ISC license. No commercial game characters, logos, sounds or artwork were copied.
