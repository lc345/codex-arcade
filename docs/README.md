## Compatibility modules

[Trusted actions](../TRUSTED_ACTIONS.md), ActionProof, Scene Packs, the Python/TypeScript SDKs and the device bridge remain for existing integrations. They are not required to install or play the Codex arcade. The original 26 games and their obsolete installation guides have been removed.
