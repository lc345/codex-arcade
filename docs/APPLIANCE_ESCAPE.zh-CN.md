# 电器成精了

首间可玩的家电卖场：附身四类电器，把待修机器人送到右侧维修出口。它是可中断的物理解谜小样，不是完整沙盒大作或长篇剧情游戏。

入口：启动 `node apps/press-lab/server.js` 后打开 `/codex-stage?game=appliance-escape`。本轮本地试玩使用 4175 端口。当前作为手动选择的第十六个试玩，原有二十款随机池保持不变；没有修改已安装 Codex、hooks、皮肤、自动化或 DMG。

## 操作

| 操作 | 鼠标 / 触屏 | 键盘 |
| --- | --- | --- |
| 附身 | 点击电器、上方编号或底部电器项 | 1 台灯、2 风扇、3 扫地机、4 售货机 |
| 驾驶扫地机 | 点击空地，或从扫地机拖向目的地 | WASD / 方向键 |
| 转动其他电器 | 点击地面或拖动，瞄准那个位置 | 左右方向键微调 |
| 使用能力 | 底部主操作按钮 | 空格 / Enter / E |
| 暂停思考 | 「停下思考」，再点继续 | B |
| 重试房间 | 外层重试按钮 | R |

附身距离上限 5.6 个场景单位。超出距离的电器置灰；先移动一台电器，就能把它作为中转点。台灯被扫地机载着时不能附身，先卸下。

斜视角中高大的物体会挡住地面点击。此时使用拖拽驾驶，可在不切换附身对象的情况下指定物体后方的地面。窄屏建议放大或横屏游玩。

## 四种身体

- **台灯：** 可搬运、可旋转、可开关。照到光敏开关可供电开门；照向别处的光斑也可能吸引巡检机。初始位置照不到开关，需要搬近。
- **风扇：** 风力对前方一定扇形范围内的轻物体施加真实的 Rapier 力，可以推动带轮货架、机器人、台灯或饮料罐。先启动、观察落点，再关掉。
- **扫地机：** 物理驱动，不穿墙。距离 1.5 内可拾取台灯或机器人，通过固定关节装载；载物时速度降低。卸载前检查前方空间，不允许穿过关闭的门卸货。剧烈减速可能掉货，可重新拾取。
- **售货机：** 可旋转出罐导槽，发射带质量、速度和碰撞的饮料罐。出罐间隔 0.9 秒，场内最多五罐，防止无界堆积。饮料罐可以撞检修踏板，也可能在门已打开时卡住门缝。

家电开关在转移电流后保持原状态，因此可以同时利用多台电器。

## 三条已验证路线

1. **光敏线路：** 扫地机搬近台灯，卸载并照准光敏开关，再回去接机器人。光照供电，关灯后储电会短暂维持开门。
2. **货架配重：** 风扇把货架吹到黄色配重板上，关闭风扇，再驾车载机器人通行。配重检测重量与实际位置，不是播放预设移动动画。
3. **检修踏板：** 提前把机器人载到门附近；附身售货机，让罐子撞到红色检修踏板，利用十二秒检修窗口通过。

三条路线都由公开玩家操作和真实物理接触验证，重放器不会改写位置、分数、开门标记或胜利状态。配重板接受其他足够重的物件；开门理由可以组合。设计没有承诺任意自创路线都能成功。

## 巡检与失败

巡检机会巡逻，也会调查噪声和可见的灯光落点。红色范围显示视野，货架、售货机和分隔墙会遮挡。被看到的活动电器累积警戒值，离开视线后下降。扫地机停稳时不会继续暴露动作；不要把风扇开启后一直留在同一身体里。

警戒达到上限会失败，没有等待惩罚，可立即重试。任务开始前等待玩家第一次动作，不会在加载画面时悄悄被抓。「停下思考」冻结物理、警戒、倒计时，可在暂停中切换电器和规划方向。任务本身不受游戏影响。

## 实现与存档

- 渲染：复用本地 Three.js 0.180.0，正交斜俯视、切面卖场、原创电器模型、转轴、轮子、机械动作、灯光和阴影。没有远程模型、商业角色或游戏截图。
- 物理：复用本地 Rapier 0.17.3 与内嵌 WASM。场景物体、推动、罐子、装载关节与升降门均有实体碰撞。巡检寻路为本房间的有限巡逻/调查逻辑，不是通用导航网格。
- 声音：本地 Web Audio 合成附身、开关、装卸、出罐、检修铃和结果音效，默认静音，不含采样录音。
- 可访问性：键盘与触屏支持，主操作与状态有 DOM 文本；减少动效取消装饰性纸片、步态和电流弧线，不改变规则。完整的非视觉空间导航不是本小样已实现的能力。
- 存档：只保存白名单游戏状态、物件位置/速度、已开关电器、装载对象、门与巡检状态，校验大小与数值边界。任务结束同步冻结、保存；恢复后重建物理关节。Rapier 接触缓存重新计算，不宣称逐位一致的物理重放。
- 安全：不接收 Agent 原文、工具参数或文件内容；不授予游戏工具权限。它是经过审核的第一方包，不能因此认为任意社区 JavaScript 可安全注入。

3D 场景需要支持 WebGL 的浏览器。不可用时显示明确提示，不用伪造截图代替实际游戏。

规则、绘制、声音分别在 `apps/codex-stage/studio/appliance-escape.js`、`appliance-painter.js`、`appliance-sound.js`。合法操作重放器在 `tools/appliance-replay.mjs`，实际浏览器验证在 `tools/test-appliance-browser.mjs`。

```bash
node --test apps/codex-stage/appliance.test.js apps/codex-stage/studio.test.js
npm run build:game-packs
npm run test:appliance-browser
npm run test:studio-browser
npm test
```

浏览器脚本支持 `PLAYWRIGHT_MODULE`、`CHROME_PATH`、`STAGE_ORIGIN`；通用浏览器脚本使用 `STAGE_URL`。先启动本地服务，独立脚本默认使用 4175 端口。覆盖合法通关、挡门、冷却、遮挡、失误重试、非法存档、投罐中断恢复、鼠标、触屏、键盘、静音、减少动效和 Canvas 像素检查。模拟 Dock 回归不等于已更新并验证本机原生 Codex 安装版。

本轮只交付这一间房间与三种解法；更多物件、关卡和精选轮换由试玩反馈决定。
