# 规则走私者 / Rule Smuggler

入口：`/codex-stage?game=rule-smuggler`。三场递进的规则卡牌战术小样，手动选择的 `preview`，不进入二十款正式游戏的随机池。

## 核心体验

没有普通的攻击牌。敌人预先亮出开火方向，玩家用有限能量改变位置、弹道与命中关系，再执行回合，让对手的火力成为解题资源。

每场在六轮内消灭全部守卫，同时保住走私者和货箱。布置没有倒计时，执行前可以撤销。每轮 3 点能量，每张规则牌每轮最多一次；规则装置跨轮保留。敌人按 A、B、C 顺序开火，已被提前摧毁的敌人跳过；幸存者随后转向，新的预演立即更新。

| 牌 | 能量 | 精确规则 |
| --- | ---: | --- |
| 镜面 | 1 | 空地放 `/` 或 `\` 反射面。再次选择镜面牌或按 Q 切换放置朝向；已放置的镜面需撤销才能修改。最多保留 5 面。 |
| 换位 | 1 | 交换两个活单位，包括自己、守卫和油桶，朝向不变。货箱不可交换，交换不触发折跃。 |
| 折跃 | 2 | 连接两个空地，替换旧门对。弹道保持方向穿过；步移或推挤进入门时，出口无人则移动到出口，出口有人则停在入口。炮弹可以命中出口单位。 |
| 同频 | 1 | 连接两台敌机或油桶，替换旧连接。直接命中与爆炸伤害都会传给另一端，同一次伤害不会无限往返。不能连接自己或货箱。 |
| 推挤 | 1 | 将敌机或油桶推到相邻空格。墙、单位与镜面阻挡；进入坑立即摧毁，掉坑的油桶不爆炸。 |
| 步移 | 1 | 自己走到相邻空地，可以经过折跃；不能进入深坑、墙、镜面或其他单位。 |

哨戒炮伤害 1，轮末顺时针转向；双脉冲炮伤害 2，轮末反向；装甲炮伤害 1、耐久更高，轮末逆时针转向。油桶被击毁后对上下左右一格造成 1 伤害，可引爆其他油桶。深坑不阻挡炮弹。

## 三场内容

- **借火开场**：只开放镜面、同频、步移，理解借火与伤害传递。
- **隔墙的连锁**：开放换位、折跃；实体墙挡住射线，油桶把一次命中扩成连锁。
- **漂亮的事故**：开放推挤；装甲、双脉冲、双油桶、深坑和受威胁货箱，需要考虑至少下一轮的局势。

支持鼠标和触屏：选牌，点目标，双目标牌点两次；重复点第一个目标取消。数字 1-6 选牌，方向键选格，空格放置，Enter 执行，B 撤销，Q 改镜面方向，Escape 取消半完成选择，R 重试。桌面或放大视图更适合看完整的战术信息。

虚线是当前布置的结算预演，不是只画原始直线的装饰。命中前后的耐久同时显示。移动平台的静音、减少动效、键盘焦点与屏幕阅读器文本沿用宿主。任务完成立即冻结输入、动画和声音，下一次选中本游戏恢复，布置记录和飞行中的弹道都保留。

## 实现与安全

- `apps/codex-stage/studio/rule-smuggler.js`：纯数据规则。预演和正式结算使用同一个确定性解析器，结算按已生成的事件时间线播放。不是刚体模拟，不引入新游戏引擎。
- `rule-painter.js`：高 DPI Canvas、四角色透明图集、棋盘装置、命中与爆炸反馈；图集加载失败时使用可辨识的本地图形降级。
- `rule-sound.js`：原创 Web Audio 合成，牌种、开火、爆炸、胜负各有反馈；默认静音，停止同步清理声音。
- `rule-catalog.js`：独立 reviewed pack，素材内嵌，离线运行，无额外权限或联网资源。
- 存档键：`agent-stage:checkpoint:v1:rule-smuggler`，最多 8 KiB。保存白名单棋盘状态、能量、已用牌、撤销历史、半选目标和播放时刻；恢复时重算时间线，不信任外部结算结果。
- 只保存游戏坐标和枚举，不接收 Agent 的任务、命令、文件路径或结果。非法存档回到第一场，未知字段不进入场景或再次导出的存档。
- 非社区任意代码安装，不修改 Codex、hooks 或主题；此次仅更新源码与内置包，没有更新用户已安装的运行目录或旧 DMG。

## 验证

```bash
node --test apps/codex-stage/rule-smuggler.test.js
node tools/build-studio-assets.mjs
node tools/build-game-packs.mjs
GAME_ID=rule-smuggler STAGE_ORIGIN=http://127.0.0.1:4175 node tools/build-studio-previews.mjs
npm run test:rules-browser
```

浏览器测试使用 Playwright 和 Chrome，可通过 `PLAYWRIGHT_MODULE`、`CHROME_PATH`、`STAGE_ORIGIN` 指定本机环境。输出位于 `output/rules-qa/`。包含三场真实鼠标通关、触屏、音效、无素材降级、桌面/手机截图、冻结像素、播放途中续存以及页面刷新恢复。

规则测试另检查合法输入通关、错误目标、能量约束、取消与撤销、同频不递归叠伤、失败、存档校验，以及 40 组固定种子布置下预演与实际结果一致。全库浏览器脚本另验证模拟 Codex Dock 的停止与恢复，不冒充实际 CDP 安装测试。

这是三场可玩小样，不是经过大规模平衡验证的完整卡牌产品；没有牌组构筑、随机抽卡、付费内容或无限关卡。玩家对组合策略与难度的真实反馈，仍是下一轮迭代依据。
