# 三种新玩法

本轮不扩张单键受虐游戏的数量，先补三个不同的体验：连锁破坏、慢节奏经营拼图、滑稽物理实验。它们是可完整试玩的小样，不是长篇商业游戏。

启动 `npm run serve:codex-stage`，访问服务打印的地址并加上 `/codex-stage?collection=variety`。也可用 `?game=marble-demolition`、`?game=pocket-town`、`?game=clockout-clearout` 单独打开。

## 弹珠拆迁队

- 操作：在场地内按住瞄准，松开发射一串五颗弹珠；也可左右键瞄准、空格发射。
- 三个街区，每区七次发射。清空后选一项改装：分裂、金属导电或重击破甲。组合会改变真实碰撞效果，不是纯粒子特效。
- 视觉：像素街机楼块、弹道与连击；声音：弹射、碰撞、分裂和电弧。
- 打空可以重试当前街区，保留已获得模块。任务中断时，尚未结束的一发回到发射前；已结算的砖块和模块保留。

## 口袋小镇

- 操作：点亮边框的空地放置下一块建筑；可随时撤销。方向键选格、空格放置，B 撤销。
- 十五块用地，固定顺序为住宅、花园、住宅、商店、铁道，共三组。没有倒计时。
- 花园旁的住宅亮灯；相邻至少两户住宅的商店开门；铁道必须连到中央车站才计分、通车。只计正交相邻。
- 目标：六户亮灯住宅、三家营业商店、三块通车铁道。布局不满足条件时可逐步撤销重排，不会自动算赢。
- 视觉：真实 Three.js 立体小镇，发光窗户、摊位、树木、行人和沿轨道行驶的小火车；声音：轻柔放置与完成和弦。
- 每次放置都保存为有上限的格子序列，恢复时重新验证邻接和计算结果。

## 下班清场

- 操作：点一根支撑柱，家具沿木板和斜坡滑进货车；左右键选择，空格抽掉。失败可立即重试。
- 三车短挑战：正常装车、反向装车、额外叠放物件。选错支撑会真正掉出画面。
- Matter.js 决定木板倾斜、家具碰撞、滚落和堆叠。家具完整进入车厢并稳定至少 400ms 才计数。
- 视觉：Three.js 玩具仓库，带表情的洗衣机、电视、纸箱与台灯；音效来自本地合成。
- 任务中断会保留已装完的车；未装完的一车从抽柱前重来。最终画面通过固定物理回放重建，不接受存档中的任意刚体坐标。

## 运行边界

- 三款都是 `preview`，只在手动选择时运行；原有 20 款稳定随机池和 8 款单键挑战不变。
- 本地画面、声音、存档，不获取任务正文、命令、输出或网络内容。
- 任务结束同步停止输入、物理、动画和声音。默认静音；减少动效关闭拖尾、碎片或装饰摆动，但保留玩法必需运动。
- WebGL 不可用时，两个立体游戏退回可玩的二维示意图；命中区域一起切换。
- 采用已有 Matter.js 0.20.0、Three.js 0.180.0 和浏览器 Web Audio，不增加玩家需要安装的软件。
- 这次只更新源码、生成包和本地预览，不修改已安装的 Codex、hook、启动项或旧 DMG。

## 开发与验证

主要入口为 `studio/variety-catalog.js` 和 `studio/registry.js`。三个 world 独立实现规则；`variety-session.js` 仅共享输入/生命周期/存档外壳。`variety-3d.js` 共享镜头、材质缓存、DPR、离屏 WebGL 和回收机制，不共享游戏规则。

```sh
node --test apps/codex-stage/variety.test.js
node tools/build-game-packs.mjs
STAGE_ORIGIN=http://127.0.0.1:4177 npm run test:variety-browser
STAGE_ORIGIN=http://127.0.0.1:4177 npm run test:game-collections-browser
```

浏览器脚本需要 Playwright / Chromium，支持用 `PLAYWRIGHT_MODULE` 和 `CHROME_PATH` 指向现有安装。截图与报告输出到 `output/variety-qa/`。规则测试覆盖可通关路径、失败、取消输入、模块真实效果、存档校验和任务结束；浏览器测试用真实鼠标/触屏输入通关，检查高 DPI、WebGL、Canvas 像素、静音、减少动效、无 WebGL 降级、离线包、本地续玩和模拟 Dock 的结束事件。模拟 Dock 通过不等于已经在当前安装的 Codex 内完成发布。
