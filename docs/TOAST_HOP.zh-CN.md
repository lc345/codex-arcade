# 吐司别掉

一个操作、十次落地。按住压扁吐司，松手跳向右侧下一座餐台；掉落后回到起点，保留最远纪录。相比「电器成精了」，本作不需要切角色、瞄准、找机关或管理技能。

本地入口：`/codex-stage?game=toast-hop`。当前开发服务使用 `http://127.0.0.1:4175`。本作是手动试玩包，未加入二十款默认随机池；源代码更新不会修改已安装 Codex、hooks、皮肤或既有 DMG。

## 操作与目标

- 鼠标：在画布内按住左键蓄力，松开起跳。鼠标所在位置不影响方向，始终向右。
- 触屏：按住画布后松开。
- 键盘：按住空格或 Enter，松开起跳。
- 外层「蓄力 / 起跳」按钮提供等价的两次点击方式，方便不便长按的用户。
- 蓄力 0.9 秒达到上限，继续按住不会突然自动发射。空中不能改变方向、二段跳或使用技能。
- 要按顺序落到十座餐台，触碰侧边或跳过目标不能得分。餐台上的彩色平直边缘就是碰撞位置；吐司中心需要落在边缘内，成功后立即站稳。
- R 或重试按钮可以随时回起点。失败后自动在约 0.38 秒重开，也可以直接按住开始下一次。

## 简单但难的设计

十跳是一个连续挑战，没有中间存档点，失败会归零。前段餐台较宽，帮助形成按压时长与跳距的直觉；后段变窄、错层，四座餐台按照固定周期水平移动。没有隐藏陷阱、随机变速、付费复活或等待惩罚。

上一跳失败时记录的是越过目标台面高度时的位置差，不是随机嘲讽。回到那一跳时会在目标旁显示相对落点与「短 / 过」的距离，帮助调整手感。首次越过台面时的差值是游戏逻辑坐标像素，不是不同显示器上的 CSS 像素。最佳进度、失败次数本地保留；正中餐台有额外反馈和少量加分，普通落地同样有效。

浏览器自动玩家通过相同按住/松开接口完成全部十跳，用于证明关卡可过；它并不代表真人首次游玩的难度或乐趣已经经过用户研究。

## 中断与隐私

任务结束同步停止输入、物理、画面更新和声音。起跳后的位置与速度保存，下次恢复继续该跳；正在蓄力时取消这次蓄力，恢复站立，避免失焦误跳。失焦、系统取消触屏以及画布外松手都不会发射。

本地 checkpoint 限长并校验枚举、数值范围、身体位置与胜利状态。只含本游戏进度，不含任务文本、工具调用、命令或路径。Matter 的接触缓存不保存，因此不承诺跨版本逐位一致重放。游戏是受审查的第一方 JavaScript 包，不是任意社区脚本的安全沙箱。

## 画面与声音

- Matter.js 0.20.0：本地固定 120Hz 物理；台面碰撞、固定跳跃冲量、移动餐台和真实着陆检测。
- Canvas 2D：独立手绘早餐店背景，代码绘制的吐司、压扁/拉伸/回弹、陶瓷台面、面包屑、相机跟随；高 DPI 画布和低动效模式。
- 内置 imagegen 生成背景，保存为 `apps/codex-stage/assets/studio/toast-hop-art.jpg`，离线嵌入只属于本作的包。提示词及来源在 `assets/studio/ARTWORK.md`，摘要在 `art-manifest.json`。
- Web Audio：原创合成压缩声、弹跳声、瓷器落地声、失败下滑音及通关音。默认静音，任务停止时终止所有声音。
