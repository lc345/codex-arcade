# 精选轮换

从已经获得正向反馈且未退役的作品中建立 7 款池，不把所有实验样品混在一起。
打开 `/codex-stage?collection=curated` 即可试玩。源码版 lazy Codex Dock 的游戏菜单显示“精选轮换 · 7 款”。

| 游戏 | 核心体验 |
| --- | --- |
| 吐司别掉 | 控制跳跃距离 |
| 叠到天上 | 找准时机堆叠 |
| 别被夹扁 | 走停躲压机 |
| 松手邮局 | 观察摆动再放手 |
| 弹珠拆迁队 | 弹射与连锁破坏 |
| 磁力暴走 | 城市收集、撞散和回收 |
| 借弹还弹 | 吸收、躲避、反击 Boss |

## 选择规则

- 每个新任务从洗牌袋抽一款，7 款一轮不重复；同一轮次之外也避免紧邻重复游戏。
- 剩余候选允许时，优先避开上一款的类型；不宣称严格的全局类型排程。
- 同一任务不因工具切换或重复开始事件换游戏。
- 任务中修改轮换模式，下一个任务才应用；主动点击具体游戏仍可以立即切换。
- 0.9.0 删除旧 26 款时，两种模式曾共同使用这 7 款。现在原生任务小窗默认从 100 款完整池抽取；这里的“精选轮换”仍然只有 7 款，两者不能相加计数，完整池中的预览作品也不因此升级为稳定版。
- 《假装是雕像》仍手动选择。Godot 拳击、购物车、收线仍是独立入口，本次没有假称完成它们的 Dock 集成。

## 加载与停止

精选使用现有 reviewed pack 白名单、SHA-256 和 8 MiB 单包上限，只加载选中的作品。运行时最多缓存两份工厂，不接受社区任意 JS。
《借弹还弹》和《假装是雕像》新增 Canvas 适配器，共用输入释放、异步素材加载、声音、暂停和关卡检查点流程。原始 Agent 事件不会传入游戏世界。
任务结束立即停输入、模拟、动画和声音，再保存有界检查点。不同游戏保留各自原有存档方式，不强行把所有游戏改成逐帧续玩。

## 安装与验证

```bash
node tools/build-game-packs.mjs
node tools/test-curated-browser.mjs
# 更新本机安装副本时，另行运行现有安装器：
bash macos/scripts/install-agent-stage-macos.sh
```

此次完成源码、静态包和浏览器测试，没有自动重装本机 companion 或重启 Codex。历史 DMG 不会自动含有本次变化。lazy Dock 修订为 0.11.0，使更新后的 companion 能替换旧 overlay；仅更改工作区文件不会升级旧进程。

浏览器验证包括完整 7 款洗牌、单包真实加载、Canvas 非空、任务结束冻结、保存、窄屏；本地模拟 Codex Shell 验证 lazy relay、同任务稳定选择、长按、放大、停止和清理，并保留侧栏、编辑区和模拟 Dream Skin 样式节点。报告在 `output/curated-qa/report.json`。这些不等于已经在用户当前 Codex 进程实测。
