# 三种美术路线的可交互小样

2026-09-20。目标是验证美术、镜头、动作和声音是否真正不同，不扩大正式随机池。

## 试玩

启动源码服务：`PORT=4175 node apps/press-lab/server.js`。

打开 `http://127.0.0.1:4175/codex-stage?collection=contrast`。顶部只显示三款小样，可随时切换、放大、开启声音。默认静音。无 hooks 参数时是三分钟模拟任务；“结束任务”立即停止游戏与音频。

三款均接入现有 reviewed pack、Pack Host 与 Dock 的目录，仍标为 `preview`，不会进入二十款正式作品的随机池。源码试玩与已安装应用是两个独立运行目录；本次没有覆盖已安装应用、hooks 或 Codex 注入配置。需要安装更新时使用项目原有安装器。

## 雨线快递 / Rainline

- 媒介：320x180 原生像素画布，最近邻放大。分层滚动街道、店铺、电线、招牌、雨线与邮差在同一像素网格上绘制。
- 镜头：侧视跟随，非俯视微缩世界。
- 动作：四拍跑步姿态、二段跳、冲刺、围巾与衣摆变化。碰撞由 Matter.js 负责。
- 操作：单击或空格跳跃，可以二段跳；B 冲刺；左方向键返回。默认向右跑，收集三封急件后到达末班车。坠落回到这一段，不丢已取得的信。
- 声音：短促方波旋律、噪声冲刺与独立送达旋律。
- 三条规则：角色和世界使用同一像素密度；动作先读轮廓再看细节；物理障碍对应可见物件。
- 禁止沿用：圆角机器人、写实插画背景、等距岛屿镜头。

## 墨影档案 / The Ink Archive

- 媒介：原创生成铜版画书房、本地位图、衬线排印、刻度放大镜、档案纸与封条。
- 镜头：固定近距离特写。主物件直接位于书房插画中，没有覆盖一个无关的棋盘。
- 动作：镜头内真实局部放大、按住显影、证物归档、三位封条解锁。
- 操作：按住怀表、钥匙和窗图约 0.7 秒，读取隐记；三件齐全后，按图示顺序设置编号并揭开封条。键盘左右选择证物，按住空格显影；封条阶段左右选位、上下改数、Enter 解封。
- 声音：带颗粒的纸张摩擦、棘轮、封条撕开；不复用像素游戏的收集旋律。
- 三条规则：以排线和明暗建立层次；所有信息像档案本身的一部分；动效克制但能解释观察结果。
- 禁止沿用：彩色宝石、塑料机器人、霓虹粒子。
- 局限：这是一个单案美术与操作验证，三个隐记位置和谜底固定，不是完整侦探游戏；没有制作长篇分支剧情。

## 末班电梯 / Last Lift

- 媒介：480x270 内部 3D 渲染、原创磨损墙面和瓷砖纹理、金属部件、复古采样。并非等距相机上添加像素滤镜。
- 镜头：73 度透视、人眼高度、完整房间尺度；拖动转头、点击地面移动。
- 动作：走近取保险丝、修复配电箱、呼叫电梯、门扇打开、走进轿厢。
- 操作：WASD / 方向键移动，鼠标拖动转头，近距离点击物件或 E / 空格互动，B 转身。触屏可拖动视角、点地面移动、点物件互动。
- 规则：Rapier 胶囊角色控制器处理墙体与门碰撞；必须取得保险丝再供电，必须开门再进入，不会点远处按钮直接通关。
- 声音：颗粒脚步、非谐波金属响、供电机械声、开门摩擦和到站铃。
- 三条规则：镜头处于空间内而不是空间上方；信息来自房间内的部件；材质体现磨损与使用痕迹。
- 禁止沿用：柔和微缩玩具、漂浮岛、头顶分数气泡。
- 局限：需要 WebGL；无 WebGL 时明确报告不可用，不冒充 3D 成功。小样只有一间电梯候梯厅，无跳吓、战斗或开放世界。

## 生命周期与范围

- 三款通过现有 `createStudioRuntime` 启停，没有私有 RAF、网络资源或后台音频循环。
- 暂停、失焦、页面隐藏清除按键和拖拽状态；任务完成同步冻结模拟、渲染与音效。
- 世界对象不接收任务文本、命令、路径或工具输出。素材只存在本地。
- `contrast-sound.js` 提供三种独立声音语言；未修改原游戏音色。
- 这是风格验收用单关小样，暂不做跨任务存档。下一次任务或重新试玩从关卡起点开始。
- 外层游戏库继续共用；各游戏不调用旧的公共角色、宝石、棋盘或 HUD 绘制器。

## 工具与素材

这轮使用已有 Canvas、Matter、Three.js 和 Rapier，没有要求安装新游戏引擎。像素角色由代码逐姿态绘制；版画使用内置 imagegen 制作原创资产；第一人称场景使用程序化几何和局部纹理。没有声称这些资产由 Aseprite、Krita 或 Blender 导出。

代码和原创程序化素材采用 Apache-2.0。生成位图依项目素材授权分发，不声明排他版权。完整来源见 `apps/codex-stage/assets/studio/ARTWORK.md`，实际 JPEG 摘要见 `art-manifest.json`；`.png` 封面来自真实游戏截图。

## 验证

```bash
node --test apps/codex-stage/contrast.test.js
node tools/build-studio-assets.mjs
node tools/build-game-packs.mjs
STAGE_ORIGIN=http://127.0.0.1:4175 node tools/test-contrast-browser.mjs
STAGE_ORIGIN=http://127.0.0.1:4175 node tools/test-contrast-app.mjs
```

浏览器脚本需要 Playwright 与 Chrome，可通过 `PLAYWRIGHT_MODULE` / `CHROME_PATH` 指定已有安装。截图和报告输出到 `output/contrast-qa/`。包含桌面与 390px 触屏、减少动效、静音/开启音频、实际解封和维修流程、停止后像素/状态/音频不变、销毁 WebGL、懒加载包、放大与页面无溢出检查。

美术验收仍需要人工试玩：遮住名称后能否分辨三款；操作五秒后节奏是否明显不同；前景是否与背景一致；小窗口能否识别目标。自动化测试不等于“足够好玩”。
