# 骰子改装厂

一个可玩完整流程的构筑小样：三颗骰子、三台设备、十二种骰面、六场连续战斗。重点是改变下一轮的可能性，而不只是投出更大的数字。

入口：启动 `node apps/press-lab/server.js`，打开 `/codex-stage?game=dice-foundry`。本轮本地服务使用端口 4175。当前为手动选择的试玩，不加入原有二十款随机池，不修改已安装 Codex、hooks、皮肤或 DMG。

## 第一次玩

1. 点击「投骰」。选择值得保留的骰子旁的锁，每回合可以重掷未锁定骰子一次。
2. 将三颗骰子拖进设备。也可以先点击骰子，再点击设备。交换位置会更新输出和自损预估。
3. 点击「执行」。三台设备从左到右运行，随后敌人反击。电能可以保留到下一轮，护盾不能。
4. 拆解敌人后，选择三个奖励模块之一，再点击一颗骰子的某个面，将其替换。原始点数不变。
5. 前往下一场时恢复 8 点耐久，上限 32。共六场；打倒总装机才算完成一轮。

鼠标和触屏都可以拖拽装配。窄屏建议横屏或放大游玩。画布聚焦后，`1/2/3` 选骰，`4/5/6` 装入设备，`L` 锁定，空格/回车执行，`B` 重掷或撤销刚安装的模块，`R` 重试本场，Esc 取消拖拽。改装时 `1/2/3` 选奖励，方向键选骰面，回车安装。

## 设备与组合

| 设备 | 实际规则 |
| --- | --- |
| 预充舱 | 骰面生效前先增加 2 电能，任何骰面都能利用 |
| 增幅器 | 当前骰面的效果点数增加 2；不改变原始点数 |
| 输出口 | 当前骰面的直接伤害增加 2；不增强反击伤害 |

典型选择：先蓄电后放电可集中输出；先护盾再反击可把敌人攻势变成伤害；倍增只放大下一次直接攻击；超频之后接冷却可以避免过热。复写复制前一个非复写骰面的基础效果，不复制设备加成，也不递归复制。

| 骰面 | 效果（P 为效果点数） |
| --- | --- |
| 冲击 | P + 2 直接伤害 |
| 蓄电 | 增加 P 电能，最多 18，跨回合保留 |
| 护盾 | 增加 P + 2 护盾 |
| 放电 | 消耗全部电能，造成电能 x 2 + P 直接伤害 |
| 反击 | 增加 P 护盾，本回合反击实际挡住伤害的两倍，再扣敌方装甲 |
| 复写 | 用自己的效果点数复制前一基础效果；没有前项则充 2 电 |
| 超频 | P x 2 + 5 直接伤害，增加 4 热量 |
| 冷却 | 减少 P + 2 热量，修复 2 耐久 |
| 拆取 | P + 1 直接伤害，修复 2 耐久 |
| 电容 | 增加 floor(P / 2) + 2 电能，以及 floor(P / 2) 护盾 |
| 倍增 | 下一次直接伤害翻倍，不叠乘，回合结束清除 |
| 低频 | 原始点数不大于 3 时造成 10 伤害并加 4 护盾，否则加 2 电 |

直接伤害和反击各自扣除敌方装甲。三台设备运行结束后，热量达到 8 会损失 8 耐久并排掉 6 热，即使敌人已被击倒仍然检查过热；之后每回合自然散热 1。自己耐久归零优先判负，不能用同归于尽跳过关卡。敌人从第五回合开始逐渐加强，防守不能无限拖延。

## 六场战斗

冲床学徒让玩家理解装配；保险柜队长引入装甲；漏电线圈干扰电能存储；翻修拳王要求应对攻击节奏；高压守卫增加热量压力；六面总装机检验整套构筑。六场行为配置使用四种原创敌人外形，不宣称六套独立角色素材。

奖励从五组固定选择中产生，每场只能安装一次。前往下一场之前可撤销安装；撤销不会刷奖励或恢复耐久。失败重试恢复本场入口的构筑、耐久、电能、热量和随机序列，而不是满血复活。

## 中断与隐私

- Agent 结束时同步冻结游戏输入、模拟、动画与音频，保存本地游戏状态。下次活动恢复同一轮。
- 投骰在动画开始前提交结果。暂停、刷新、恢复不会重抽骰面，也不会重新获得重掷次数。
- 战斗中断保存基础状态和结算时间，恢复时重建相同的确定性时间线，已经发生的伤害不再执行一次。
- 存档有版本、白名单、数值/数组边界及 8KB 大小校验。只保存游戏数据，不接收 prompt、工具参数、文件路径或执行结果。
- 默认静音，可开启原创合成音效；减少动效保留规则与结果，取消摇摆和移动特效。资源加载失败时以代码图形替代敌人，规则不变。

## 实现与范围

规则位于 `apps/codex-stage/studio/dice-foundry.js`，Canvas 绘制位于 `dice-painter.js`，本地 Web Audio 位于 `dice-sound.js`。这是回合制确定性规则系统，骰子翻滚是已提交随机结果的视觉呈现，不是假称的刚体投骰物理。没有新引擎、网络对战、付费道具或永久成长系统。

敌人素材由内置 OpenAI imagegen 工具原创生成，再转为透明 WebP；完整提示词和许可说明见 `apps/codex-stage/assets/studio/ARTWORK.md`。封面是实际游戏截图，不是概念图。

```bash
node --test apps/codex-stage/dice.test.js apps/codex-stage/studio.test.js
npm run test:dice-browser
npm run test:studio-browser
npm test
```

浏览器脚本支持 `PLAYWRIGHT_MODULE`、`CHROME_PATH` 和 `STAGE_ORIGIN`；通用浏览器脚本使用 `STAGE_URL`。需要先启动本地服务，默认独立脚本使用 4175 端口。

测试覆盖全部骰面、不同设备顺序、盾反/热量、奖励撤销、失败重试、结算中断恢复、静音、键盘、触屏、资源缺失和浏览器重载。完整鼠标测试通过真实拖拽和选择完成六场战斗，不直接修改场景来伪造胜利。模拟 Dock 测试不等同于已安装原生 Codex 实机验证。
