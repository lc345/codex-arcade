# 磁力暴走

本轮把原来的吸附小样升级为一趟完整的城市回收任务：收集金属成长，接上河岸废弃巴士，躲开车流拖回工厂，最后看它被压成金属锭。不继续扩展《口袋小镇》和《下班清场》，也不删除既有作品。

## 试玩

启动 `npm run serve:codex-stage`，打开 `/codex-stage?game=magnet-rampage`。开发机已有服务时使用其实际端口。

- 鼠标移动：驾驶；靠近会自动吸附，不需要连点。
- 触屏：按住并拖动；松手立即制动。
- 键盘：方向键或 WASD；R 重新开始。
- 页面音量按钮：默认静音，主动开启后播放本地合成音效。
- 三段目标：收集金属、接上巴士、送回工厂。吸到巴士并不算通关，必须将巴士和磁铁都带进回收厂，再完成 2.6 秒的拆解收束。
- 磁力达到 20、60、110、180 依次解锁工具、单车、售货机和废弃车辆。行驶中的车辆是障碍，不能吸走。
- 普通碰撞会甩掉外层零件；严重碰撞最多掉五件，长货车重撞可以把巴士撞脱钩。掉落物可以接回，首次收集才增加磁力，不会因为掉落而反复升降级。
- 无倒计时、无强制重开、无账号和网络依赖。通关可重新开始。

## 物理与画面

地图从 1400 × 780 扩至 2800 × 1560，面积四倍，包含后巷回收站、商业十字街和河岸巴士桥。商店、护栏、水域和隔离柱均有物理边界。窄路方便小体积穿行；外圈宽路更适合拖着巴士返程。小地图持续显示工厂、巴士、自己和车流，返程时标出建议宽路；画面箭头指向当前目标。

Three.js 绘制原创微缩城市；Matter.js 在水平面上处理真实复合刚体碰撞。每件吸附物增加一个近似圆形碰撞体，并非完整 3D 网格碰撞。组合体的不对称重心影响转向；尺寸影响通道通行。大物件有更缓慢的吸引与吸附节奏。

三辆小车和一辆长货车持续经过道路；货车接近主路前出现黄色警示，开启音效时有短促提示。小车在货车通行阶段让行。松开触屏或方向键只制动车辆，已经启动的车流仍然运行；暂停/Agent 完成才冻结整个世界。

减弱动效关闭附加磁力流线、碎屑、轻微摇摆和飘字上浮，保留必要的游戏移动与镜头跟随。无 WebGL 时使用同一世界投影和输入映射的 2D 降级画面。

## 生命周期与存档

沿用可信宿主的 Agent 开始/完成契约，不读取任务正文。完成会同步停止输入、物理、音频与绘制。

v2 存档保存已挂载物品 ID、首次获得记录、安全区域、交付状态，以及有效的脱钩巴士位置；不保存任务内容。恢复时在安全空地静止重组，并检查整个组合体不会穿墙，不恢复速度、按键或旧的鼠标目标。存档限制为 8 KiB，检查 ID、去重、收集顺序、解锁条件和位置边界。恢复后的车流有 2.5 秒碰撞保护。

保留 v1 兼容：旧版已吸到巴士的存档会从河岸安全区域继续返程，不直接获得新版胜利。已经交付的存档恢复为完成状态，避免重放奖励；Agent 在拆解中途结束也会立即冻结。

这是手动选择的 preview，稳定随机池仍为 20 款，总目录为 48 款。源码/浏览器包已接入，旧 DMG 和本机已安装 Codex 组件不会自动被这次源码修改替换。

## 验证入口

- `node --test apps/codex-stage/magnet.test.js`：真实移动通关、重物解锁、碰撞脱落、分数去重、存档、停止、离线包边界。
- `npm run test:magnet-browser`：桌面高 DPI 真实鼠标通关、手机真实触屏与取消、键盘、默认静音、减弱动效、WebGL 降级、页面存档、离线重启、模拟 Codex Dock 的任务结束冻结。
- `npm run test:studio-browser`：全部游戏的渲染与生命周期回归。
- `node tools/build-game-packs.mjs`：重建独立校验包。
- `GAME_ID=magnet-rampage node tools/build-studio-previews.mjs`：生成真实游戏封面；可用 `PLAYWRIGHT_MODULE`、`CHROME_PATH`、`STAGE_ORIGIN` 指向本机环境。

图像和报告生成在 `output/magnet-qa/`。模拟 Dock 不等同于验证本机正在运行的 Codex 注入，画面和自动化通关也不等同于用户对趣味性的认可。
