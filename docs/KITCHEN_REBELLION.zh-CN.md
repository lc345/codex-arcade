# 厨房保卫战 / Kitchen Rebellion

独立的五波塔防试玩，入口 `/codex-stage?game=kitchen-defense`。
它在 20 款正式游戏的随机池之外，需手动选择；本次没有修改已安装 Codex 的注入配置或运行目录，也没有发布新 DMG。

## 这一款验证什么

熟悉的塔防规则是入口，设计重点是「位置、温度和时间可以组合使用」：

- 爆米花炮连续射击，装甲降低其伤害；改装后单发伤害增加。
- 冷冻柜减速；改装扩大范围。
- 电磁炉造成范围伤害和短暂灼烧；先冷冻、再受热才触发蒸汽冲击，范围伤害伴随短暂硬直。
- 弹簧锅击退敌人，沿路线撞到后排时造成追尾伤害。总管更重，只受到部分击退。
- 下游的锅可以把敌人送回上游火力区，控制装置的位置因此会改变输出效率。
- 出餐铃短暂停住敌人，20 秒冷却。音效是反馈，不是操作成功的必要条件。

可用起手：在 5 号台放冷冻柜、3 号台放电磁炉。原有 4 号爆米花炮提供连续火力。也可以走弹簧锅加爆米花的击退路线，不必沿用这一布阵。

每波结束获得金币和三选一配方；六种配方覆盖蒸汽、弹簧、弹射、冷冻、冷却和经济。
五波使用手工编排，包含普通清扫机、高速轮组、装甲清扫机和周期充能的总管。
这是首轮玩法验证，不宣称经过大规模玩家平衡测试。当前没有多地图、长线养成、真人对抗或程序化敌人生成。

## 操作与恢复

- 鼠标/触屏：选下方厨具，再点空台位；点已有厨具后可改装。回收仅在备餐阶段开放。
- 键盘：左右选台位，上下或 1-4 选厨具，空格放置/改装，Enter 开餐，B 摇铃，U 改装，Delete 回收，R 重开。
- 鼠标停在厨具上可查看规则说明。静音、减少动效、放大由现有宿主提供。
- 任务完成同步停止模拟、输入和声音，然后保存；下一任务选择同一游戏会恢复。
- 本地键为 `agent-stage:checkpoint:v1:kitchen-defense`，保存金币、台位、敌人、弹丸、波次、配方和冷却。没有 Agent 请求、命令或任务输出。
- 存档受结构、范围、数量及 8 KiB 上限校验；异常存档回到备餐状态。通关或失败后，下次任务开始新的一班。
- 暂停不会累计离线时间。当前游戏仍是手动固定选择，未改变其他游戏的随机策略。

## 内容与技术

- 规则：`apps/codex-stage/studio/kitchen-defense.js`，独立确定性路径塔防模型，复用 Studio 固定步长内核。击退是沿路线的规则，不伪称自由刚体模拟。
- 画面：`kitchen-painter.js`，高 DPI Canvas。厨房背景由内置 imagegen 生成，交互装置、清扫机、动画和 HUD 为项目代码绘制。
- 声音：`kitchen-sound.js`，本地 Web Audio 合成，无第三方录音。声音有触发限频和同时发声上限。
- 发行：沿用 reviewed pack，图像嵌入该包，离线运行。没有新的运行时依赖。
- 验证：`node --test apps/codex-stage/kitchen.test.js` 和 `npm run test:kitchen-browser`。后者需要 Playwright 与 Chrome，可通过项目已有的 `PLAYWRIGHT_MODULE`、`CHROME_PATH`、`STAGE_ORIGIN` 环境变量指定。

## 后续创意的筛选方式

不按「把一个经典游戏换主题」批量生产。每个新方向先回答三个问题：玩家做了什么不一样的决定？什么出乎意料的结果来自规则本身？下次还有什么想试？

以下仅为待验证概念，不是已实现功能，也不声称从未有人做过：

| 方向 | 玩家控制的东西 | 值得验证的独特乐趣 |
| --- | --- | --- |
| 影子施工队 | 灯光的位置，而非人物 | 物件投影变成桥和台阶；移动一盏灯，同时改写几条路线 |
| 昨天的快递员 | 一个短片段里自己的行动 | 上一次行动成为自动重播的队友，今天和昨天的自己配合搬运 |
| 雨水乐队 | 屋檐、桶和排水路线 | 用接水、分流和倾倒让机械乐器演奏，声音也是因果线索 |
| 一口气的城市 | 一股共享的气流 | 小风车、帆船、电梯争用风；改变一个出口会改变整张地图 |
| 移动的规则 | 作用范围不同的规则牌 | 不是给角色加数值，而是把「反弹」「交换」「复制」放到场地上，改写局部行为 |

这些方向应分别制作最小互动实验，通过试玩后再决定美术管线与内容量。不要预先统一成同一种俯视地图、同一种颜色或同一种得分任务。
