# 十种奇妙小差事

试玩：`/codex-stage?collection=odd-ten`。十款新作，每款三关，不把关卡计成新游戏。球类到此暂停，本批强调时机、精细鼠标操作、变形、分拣和物理机关。

| 游戏 | 主要操作 | 成功 / 失败 | 风格 |
| --- | --- | --- | --- |
| 咔哒金库 | 按住转，绿色刻度处松手 | 打开 4 / 5 / 6 道锁；停错三次报警 | 装饰艺术、金属转盘 |
| 高压冲冲洗 | 按住拖动水枪，松开冷却 | 限时洗掉至少 130 / 144 块污渍；过热暂时停水 | 街头彩色壁画 |
| 拉链别脱轨 | 抓住拉头，沿曲线拖到底 | 拉到终点；偏离积累磨损，达到上限脱轨 | 牛仔布、金色针脚 |
| 闹钟闭嘴 | 点击黄色响铃钟 | 敲掉 8 / 10 / 12 个；误敲或漏响三次失败 | 限色像素夜景 |
| 月面停车费 | 鼠标左右引导，按住喷气 | 在目标平台轻落；落偏、落重、越界失败 | 月面仪表、低饱和太空 |
| 果冻挤挤 | 按住压扁，松开伸高 | 低门压扁、窄门伸高；撞门即重来 | 糖果色赛璐珞 |
| 行李别乱飞 | 行李拖到同色出口 | 分拣 6 / 7 / 8 件；错送或漏件三次失败 | 机场平面插画 |
| 引线理发师 | 按住划断引线 | 完成 1 / 2 / 3 批；火星到炸弹或剪到金线失败 | 工业蓝图 |
| 抽薪不倒 | 抓住木板水平抽出 | 抽出 3 / 4 / 5 层且屋顶落稳；倒塌失败 | 木纹工坊 |
| 剪一口甜 | 选时机点击剪绳 | 糖果落进罐口；擦过或超时失败 | 剪纸糖果铺 |

这些是人工设计的不同规则和画面，不是从同一个模板改颜色。金库、果冻与剪绳可以只用空格；精细指向类以鼠标或触屏为优先，同时支持方向键移动操作位置、空格按下 / 松开。键盘路由已验证，不等于每一关都做过纯键盘通关。

## 生命周期

- 开始任务后加载所选游戏，玩家开始后计时。任务结束立即冻结画面、停止声音和输入。
- 三关采用安全检查点：任务中断时保留当前关号，恢复后从该关准备态开始；不保存任意物理中间态。
- 静音、减少动效、失焦暂停、取消拖拽、离线重启均沿用现有运行时。
- 此批是源码 catalog / lazy Dock 的手选预览。默认随机池仍为 20 款，精选池仍为 8 款；不自动修改用户已安装的 Codex companion、DMG 或主题。
- `output/odd-ten-qa/dock-report.json` 是模拟 Codex Shell 的生命周期验证，不是真机安装 / 更新验收。

## 开发与素材

入口：`apps/codex-stage/odd-ten/`。`worlds.js` 是可脱离 DOM 回放的规则，`painter.js` 是十个独立画面，`catalog.js` 注册条目，`build.js` 只打包选中的代码和背景。

`lunar-lease`、`tower-unplug`、`sugar-snip` 使用本地 Matter.js；其余是定制的离散规则 / 运动判定，不虚列物理依赖。每包限制 800 KB，没有网络素材、脚本插件或 Agent 数据访问。Reviewed JavaScript 仍需代码审核，不是任意社区代码安全沙箱。

美术为本项目原创 SVG + Canvas，源文件可编辑，不依赖生成服务。背景本地光栅化为 PNG；声音为本地 Web Audio 合成。没有商业游戏角色、付费素材或采样音乐。详见[美术来源与许可证](../apps/codex-stage/odd-ten/assets/ARTWORK.md)。

```sh
node tools/build-odd-art.mjs
node tools/build-game-packs.mjs
node tools/test-odd-ten-browser.mjs
node tools/test-odd-dock.mjs
node tools/build-odd-manifest.mjs
node --test apps/codex-stage/odd-ten/*.test.mjs
```

浏览器脚本需要 Playwright 和 Chrome，可通过 `PLAYWRIGHT_MODULE`、`CHROME_PATH` 指定路径，`STAGE_ORIGIN` 默认 `http://127.0.0.1:4180`。`ODD_GAME=<id>` 只重测单款，会覆盖本批浏览器报告，正式验收要跑完整十款。
