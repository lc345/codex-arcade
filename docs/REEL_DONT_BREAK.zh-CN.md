# 收线！别断

一个主操作、三场短较量的手绘钓鱼游戏。按住收线，松开泄力；看懂对手的前摇，利用喘息窗口拉近距离。
这是独立本地试玩，不接收真实 Codex 任务，也尚未进入随机游戏池。购物车、Godot 拳王、旧游戏和已安装 Codex 均不修改。

## 试玩

已有本仓库服务时，打开 `/apps/codex-stage/reel-break/index.html`。没有服务时：

```bash
PORT=4180 node apps/press-lab/server.js
# http://127.0.0.1:4180/apps/codex-stage/reel-break/index.html
```

端口占用时复用本仓库服务，或选择另一个空闲端口。玩家不需要额外下载引擎、注册账号或安装创作软件。

- 鼠标按住画面或“收线”按钮，松开泄力。键盘聚焦画面后按住空格。手机按住画面或按钮。
- 赤尾梭：先摆尾，再短促冲刺。金腹鲷：低头后持续下潜，恢复窗口更长。蓝绸鳍：虚晃、转向和突然折返。
- 一直硬拉会断线；一直不收会脱钩；快速乱点也无法有效转动线轮。
- 收到岸边才算上岸；前两条完成后点击“下一条”，第三条后可以重新挑战整轮。
- 重试不需要等待，也不会跳过尚未完成的对手。
- 默认静音，可主动开启线轮、入水、警示、断线和上岸音效。

## 实现边界

`world.js` 是固定 120 Hz 的确定性街机规则：收线啮合、距离、张力、过载和脱钩风险共同决定结果。
它不是实测钓具或流体/绳索物理模拟，也没有使用引擎效果假冒真实受力。鱼的行为前摇与力量来自同一状态。
一轮正常回放约 50 秒，但没有以此预测 Agent 耗时；每场可随时暂停和中断。

Canvas 2D 渲染原创设计的生成式手绘素材；鱼尾采用图集条带形变，人物是随受力倾斜的剪影，鱼竿、线轮和鱼线分别绘制。
背景保持比例并裁切适配窄屏。没有预录视频冒充游戏，没有 CDN、远程素材、动态代码求值或 Agent 数据读取。
声音是本地 Web Audio 合成，最多十个声部，静音/停止/卸载立即清理。

## 生命周期与续玩

页面“开始任务/结束任务”是本地模拟器，不控制或读取真实 Agent。
结束时同步关闭输入、动画调度和声音，随后保存白名单检查点。
后台与失焦暂停并清除手势；返回后不自动按住收线。手动 `pause(true)` 必须手动解除。
加载期间停止会丢弃迟到的素材结果，不会重新激活页面。

检查点键为 `agent-stage:reel-break:v1`，仅保存关卡、时间、距离、张力等有界游戏数据；不保存任何任务内容。
未完成较量恢复为等待输入，并提供短暂的张力缓冲。已经上岸的对手保持完成，不重复收取奖励。
清空浏览器站点数据会移除记录。没有云存档、排行榜或遥测。

`window.reelPilot` 提供 start、stop、pause、destroy、snapshot、state，供本地验证使用。
正式接入仍需 reviewed pack 封装、素材预加载、Dock 尺寸与真实任务生命周期验收；这个独立页面不代表已完成正式安装分发。
