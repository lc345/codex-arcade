# 购物车下坡王

一条从坡顶街区经过集市、最终进入码头派对的 3D 物理配送赛道。
本作是独立本地试玩，验证新的视角、美术和操作；没有接入真实 Codex 任务或随机游戏池。
《破烂拳王》《磁力暴走》及其余目录游戏、已安装的 Codex、已发布 DMG 均未修改。

## 试玩

启动本地服务后打开 `/apps/codex-stage/cart-downhill/index.html`：

```bash
PORT=4180 node apps/press-lab/server.js
# http://127.0.0.1:4180/apps/codex-stage/cart-downhill/index.html
```

如果已有本仓库服务，可直接使用它的端口；另开服务时请选择空闲端口。
玩家不需要安装 Blender 或额外引擎。所有模型、物理、渲染与音效均来自本机，不依赖 CDN。

## 操作与目标

- 点“出发”，或在场景中点击/按 Enter 开始。鼠标左右移动控制转向，按住左键刹车，松开顺坡前进。
- 方向键左右转向，空格刹车，R 从最近路段重试。无关按键不触发出发。
- 手机拖动场景控制转向，独立“刹车”按钮可按住；触摸取消会清除手势，不残留方向或刹车。
- 蛋糕是物理货物：不要甩出车外，也不要把购物车开翻。杂物洒落不一定结束挑战。
- 穿过集市的箱堆、门槛和横穿车辆；进入终点旗线后减速，在派对区域稳住车，才算送达。
- 单纯跑到路程数字为零不算成功；冲过派对、翻车或丢失蛋糕都可能失败。
- 碰撞后可以刹车和反打方向补救，不会一碰就直接判输。

声音默认关闭。声音开启后包含滚轮噪声、刹车、碰撞、货物洒落、路段及结果音效。
静音不影响判断，减少动效会降低额外人物动作；必要的车辆运动和追尾镜头仍会保留。

## 真实实现

- 渲染：本地 Three.js 0.180.0，透视追尾镜头、动态阴影与 glTF 模型。
- 物理：本地 Rapier 0.17.3 的四轮 raycast vehicle controller，加上独立动态货物、箱堆和运动学交通车辆。重力提供下坡动力，低速有少量街机辅助推力。
- 美术：Blender 4.5.14 原创购物车、软陶风人物、蛋糕、木箱、水果、汽车、摊位与房屋。头、腿和车轮保留独立节点；材质、布纹、标牌、灯光与道路由本地渲染器完成。
- 音效：原创 Web Audio 合成与确定性噪声缓冲，不下载音频。
- 操作和胜负规则只使用游戏数据，不接触 Agent 内容、文件、工具参数或授权。

这是一个约 260 米的连续短赛道，不是开放世界。箱堆可以被推散，但没有逐片木材断裂；人物是分层节点动画，不是完整布娃娃。路边摊位桌面是固定碰撞体，不是整个摊位都能拆毁。

## 中断与恢复

页面“开始任务/结束任务”是本地生命周期模拟器，不会控制或读取真实 Agent。
结束时同步禁用输入、停止物理与 RAF、静音全部声部，再保存本机检查点。
后台暂停、触摸取消、失焦、资源加载期间结束以及卸载均有清理路径。

检查点只包含版本、已到达路段和蛋糕完整度，键名为 `agent-stage:cart-downhill:v1`。
恢复时在最近进入的路段起点停车，等待新输入；不是保存每个箱子和轮子的瞬时状态。
主动“重试”会从该路段补齐货物并恢复蛋糕；本次驾驶用时也从零计起，不是排行榜总用时。

已暴露的 `window.cartPilot` 只用于试玩与生命周期验证，包含 start、stop、pause、destroy、snapshot、state。
正式接入 Codex Dock 前，还需要 reviewed pack 封装、资源缓存策略及嵌入尺寸验收；当前不改动旧随机池。

## 维护与素材

```bash
# 维护者需要已安装 Blender；可用 BLENDER_BIN 指定路径
npm run build:cart-assets

# 规则、声音与素材完整性
npm run test:cart

# 本地 Chrome + Playwright，默认服务在 4180
npm run test:cart-browser
```

浏览器脚本允许用 `PLAYWRIGHT_MODULE`、`CHROME_PATH`、`STAGE_ORIGIN` 指定测试环境。
编辑器脚本为 `tools/art/build-cart-assets.py`；运行时源码在 `apps/codex-stage/cart-downhill/`。
`assets/seaside.blend` 保留可编辑源文件，`seaside.glb` 约 1 MiB，`provenance.json` 记录原始脚本与素材 SHA-256。
素材、代码及声音源码为 Apache-2.0；Three.js 与 Rapier 的上游许可证保留在原有 vendor 目录。
玩家只下载 GLB，不需要下载 Blender 源文件或安装 Blender。

## 验证范围

2026-09-30 本机验证：426 项 JavaScript/TypeScript 测试与 9 项 Python 测试通过。
Chrome 桌面和移动触屏模拟验收通过，浏览器错误为零；额外检查手机全屏下购物车与人物的投影边界，避免主体被裁切。

自动测试覆盖等待输入、真实减速、路段检查点、无效数据、停车送达、撞散箱堆、盲开失败、货物甩落、撞车后救回、停止后刚体冻结、声音停止、素材摘要与无外部资源。
浏览器测试使用真实鼠标跑过三个区域并停车送达；另行制造交通碰撞，检查模型显示、画布像素、键盘、移动触控、静音、减少动效、离线继续、重载恢复、停止、卸载后事件与延迟加载。
截图和报告写入 `output/cart-qa/`。手机检查为 Chrome 触屏模拟，不表示已完成真机 Safari 或所有设备的兼容性认证。
