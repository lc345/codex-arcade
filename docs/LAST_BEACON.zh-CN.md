# 最后信标 / Last Beacon

原创第三人称小型吃鸡试玩。重点验证搜装备、瞄准交火、掩体、缩圈和最后一人生存的完整循环，不复制 PUBG 的人物、地图或素材。

## 运行

已有仓库服务时打开 `/apps/codex-stage/last-beacon/index.html`。否则：

```sh
PORT=4180 npm run serve:codex-stage
# http://127.0.0.1:4180/apps/codex-stage/last-beacon/index.html
```

浏览器载入后点击“进入战场”。默认静音，可用左下角音量按钮开启。桌面 Chrome 为本轮实测环境；内嵌浏览器如果不允许锁定鼠标，可按住鼠标右键拖动转向，或用左右方向键转向。

## 操作

| 操作 | 输入 |
| --- | --- |
| 移动 | WASD；上下方向键也可前后走 |
| 瞄准 | 鼠标；右键精确瞄准 |
| 射击 | 鼠标左键，或空格 |
| 冲刺 | Shift + 移动 |
| 拾取 | E，或物资图标 |
| 换弹 | R，或换弹图标；空弹匣继续射击也会换弹 |
| 治疗 | H，或医疗图标；移动与开火会打断 |
| 释放鼠标并暂停 | Esc |
| 手机 | 左侧摇杆移动，拖动画面转向，右侧按钮开火 |

出发点前方有步枪、护甲和医疗包。目标是成为最后一位生还者。共有你和 7 名机器人，没有真人联机。机器人会相互交战、绕开障碍、换弹和向安全区内移动；并非只攻击玩家，也不会按时间自动死亡。

## 场景与规则

- 一张海岸站地图：可进入的仓库、集装箱、混凝土掩体、岩石、废弃车辆与信号塔。
- 三种枪分别有真实弹匣、射击间隔、散布、射程、换弹时间和伤害；近处霰弹枪会发出多条弹丸射线。
- Rapier 负责胶囊角色碰撞和射线命中。仓库墙体能挡子弹，低掩体可以越顶射击。没有趴下、跳跃、爆头倍率或可驾驶车辆。
- 安全区在 25 秒后开始缩小，分四段收缩，圈外持续掉血。不制造假的战斗进度或击杀。
- 命中提示、近处枪声、枪口焰、弹道、小地图近期枪声位置、淘汰记录与最后排名。
- 装备资源和音效全部本地加载，不需要账号、模型 API 或联网服务器。

## 生命周期边界

这是独立本地试玩页。“开始任务 / 结束任务”是生命周期模拟器，不代表已经接上当前 Codex 真实任务。结束会取消帧循环、清空输入、停止音效并冻结战局；重新开始先回到无按键按住的准备状态。离开窗口、切换标签、释放鼠标会暂停。

检查点键为 `agent-stage:last-beacon:v1`，只保存有界战局数据，如位置、生命、装备和已拾取物资，不保存任何 Agent 任务内容。结束的一局不恢复成正在交火的状态。尚未加入 catalog、随机池、精选池、已安装 Companion 或发布 DMG；其他游戏保持不变。

## 工具与素材

- Three.js 0.180.0：透视相机、光照、阴影和 GLB 模型。
- Rapier 0.17.3：角色碰撞、墙体和射线。
- [Yuka 0.7.6](https://github.com/Mugen87/yuka/tree/8440c4fe3282088ecdace32701e196d4b12a715c)：导航图和 A*；版本、摘要、MIT 许可在 `vendor/`。
- Blender 4.5.14：原创角色、枪械和物资模型；运行时动画控制模型的命名关节，不依赖远程模型。
- 内置 image_gen：原创地面纹理；Web Audio：原创合成音效。
- 素材提示词、来源、各文件摘要与许可证见 [ARTWORK.md](../apps/codex-stage/last-beacon/assets/ARTWORK.md) 和同目录 `provenance.json`。生成素材不作著作权独占保证；Lucide 图标单独遵循 ISC。

玩法参考仅限 [PUBG 官方玩法概述](https://www.pubg.com/en-asia/game-info/overview) 与[安全区说明](https://support.pubg.com/hc/en-us/articles/115004168813-What-is-the-blue-circle)。没有复制其代码、标志、角色、地图或音效。

## 验证与重建

```sh
npm run test:beacon
npm run test:beacon-browser
npm run build:beacon-manifest
# 仅维护者需要 Blender；普通玩家不需要安装。
BLENDER_BIN=/path/to/Blender npm run build:beacon-assets
```

浏览器测试需要 Playwright 和 Chrome，可通过 `PLAYWRIGHT_MODULE`、`CHROME_PATH`、`STAGE_ORIGIN` 指定本机路径。

本轮 16 项专项测试通过：碰撞和遮挡、击杀与未命中、弹药与治疗、缩圈、导航、完整 8 人对局、机器人互相交战、检查点、停止冻结、素材许可摘要和音频清理。规则回放只走公开操作，不修改血量、敌人或比分。

Chrome 浏览器实测通过真实 WASD 移动、E 捡枪、鼠标瞄准击杀、R 换弹；多指触屏同时移动、转向、射击；静音、减少动效、暂停、任务结束冻结、保存再载入、加载后离线和迟到加载取消。桌面与手机截图及报告在 `output/beacon-qa/`，页面运行错误为零。浏览器验证了真实交战击杀；完整七次淘汰获胜另由规则回放验证，二者不混淆。手机为触屏模拟，不等于所有实机/Safari 已验证。

全仓库回归：485 项 JS/TS 与 9 项 Python 测试通过。原 8 款精选和 20 款经典随机池未改动。
