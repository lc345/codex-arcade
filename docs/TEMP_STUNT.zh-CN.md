# 临时替身 / Temporary Stunt

状态：一个完整、可通关的原创片场试玩，不是三个片场的完整发行版。2026-09-20。

## 试玩

启动项目现有开发服务，打开 `/codex-stage?game=temp-stunt`。游戏使用独立本地包，只加载这一款的素材与 Matter.js，不需要额外下载软件。

第一场是「办公室最后一镜」：替身从发射椅起跳，穿过中间的道具玻璃，最后安全落到右侧电梯。绳索、身体关节、玻璃碰撞、复印机弹射和电梯挡板都参与实际规则。当前是 Canvas 2D 呈现的 2.5D 黏土片场，不是实时 3D 游戏。

## 操作

- 按住替身，向左后方拖动蓄力；松手开拍。拖得远，速度更快；向下拉，飞得更高。
- 在空中点击亮起的吊灯抓绳，再点击一次松开。每一条最多三次，点击本身不加分。
- 落在复印机顶部会再次弹起，纸张喷出对应真实弹射事件。
- 「慢镜头」或 `B` 切换 0.4 倍速度；物理仍按相同的 120 Hz 模拟步结算，只减少每秒执行的步数，不改变路线。
- 方向键调整力度和仰角，空格开拍或抓最近可用吊灯 / 松绳；`R` 重拍，`Escape` 取消尚未松手的拖拽。
- 支持鼠标、触屏和键盘；声音默认关闭。建议桌面展开试玩，手机也可拖拽，但小窗口中的角色和吊灯需要更精确地点击。
- 开拍前可通过顶部选项或 `1/2/3/4` 选择自由拍摄、完全不用吊灯、借复印机救场、轻拿轻放（最多打碎两块玻璃）。挑战不改变基础通关条件，达成徽记随本地存档保留。

三条经过合法输入验证的路线：直接穿窗；低角度借复印机二次弹射；普通起跳后用吊灯救场。游戏不要求唯一解，不把预定路线动画伪装成物理结果。

## 已完成内容

- 10 个刚体部件、9 个关节约束组成的替身，具有真实翻滚和碰撞。脸部表情、领带、碎片和纸张属于表现层，不改变碰撞体。
- 5 块独立道具玻璃：只在身体以足够速度撞到时破碎；没有点击自动碎玻璃或按时间发放成功。
- 2 个可抓吊灯，有限次数、可收绳的单向拉力，保留松手时的动量。
- 一个复印机弹射台和一个有实体移动挡板的电梯。撞穿至少一块玻璃、进入落位区、接触落地垫并稳定一小段时间后才算成功。
- 安全失败与立即重拍；一条拍摄最多 14 秒模拟时间，布置阶段不限时。该时间只属于游戏，与 Agent 进度无关。
- 原创片场背景、代码驱动的关节角色和道具、区分发射 / 挂钩 / 玻璃 / 复印机 / 落地 / 结果的合成音效。声音有并发上限和冷却。
- 默认静音、减少动效、ARIA 操作描述、狭窄窗口布局、无背景素材降级。
- 首次静止时短暂出现拖拽手势示意，不会代替玩家操作或发射；实际拖动或键盘调角后消失。减少动效时只显示静态示意。
- 失败反馈依据实际飞行距离、最高点、挡板接触、落地速度及玻璃状态给出下次调整方向；它是启发式建议，不声称是完整的物理原因诊断。

## 停止与存档

沿用可信游戏宿主，不修改 Codex hooks、注入器或 Dream Skin。收到任务完成后，同步停输入、物理、绘制调度和声音，然后保存本地检查点。

检查点只保存版本、十个部件的位置和速度、玻璃状态、绳索、镜次、分数、慢镜头、计时、可选挑战徽记和有限的失败反馈指标。新增字段可选，兼容旧 v1 存档。恢复时校验数组长度、有限数值、范围和状态组合，不接受任意对象直接赋给运行时。未知字段被丢弃，不包含任务提示词、路径、文件、工具输出或密钥。存档远小于宿主的 8 KiB 上限。

可以恢复腾空、挂绳或已经收工的状态。Matter 的接触缓存不写入存档，因此恢复不承诺逐浮点位一致；测试验证关键路径恢复后可完成，并且中止期间状态与声音保持不变。

## 代码与验证

- `apps/codex-stage/studio/temp-stunt.js`：独立规则与 Matter 物理。
- `studio/stunt-painter.js`：高 DPI 绘制、资源降级和视觉状态。
- `studio/stunt-sound.js`：Web Audio 原创音效。
- `studio/stunt-catalog.js`：单场景试玩元数据，暂不进默认随机池。
- `apps/codex-stage/stunt.test.js`：合法路线、失败、限次、停止、慢镜头、存档与包边界。
- `tools/test-stunt-browser.mjs`：真实鼠标 / 触屏、三条路线、素材、音效、停止与页面重载。
- `tools/test-studio-browser.mjs`：全游戏回归及模拟 Codex Dock 的新游戏恢复。模拟 Dock 不代表已经在本机原生 Codex 中重新安装验证。

```bash
node tools/build-studio-assets.mjs
node tools/build-game-packs.mjs
node --test apps/codex-stage/stunt.test.js
npm run test:stunt-browser
```

浏览器脚本接受 `PLAYWRIGHT_MODULE`、`CHROME_PATH`、`STAGE_ORIGIN`，可使用项目已有 Playwright 和 Chrome。素材来源、完整生成提示词与转换流程见 `apps/codex-stage/assets/studio/ARTWORK.md`。
