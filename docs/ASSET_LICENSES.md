Game asset folders contain `LICENSE`, `ARTWORK.md` and/or `provenance.json`. Studio assets use `apps/codex-stage/assets/studio/ARTWORK.md` and `art-manifest.json`; Godot source artwork is documented in `games/junk-champion/ARTWORK.md`. Audio is original local synthesis or code-generated WAV assets, not commercial soundtrack recordings.

Generated artwork was created for this project using built-in image generation or original scripted Blender models. The project grants rights it holds under Apache-2.0; this does not guarantee copyright protection or exclusivity for AI-generated images. Provenance records identify source, transformations and available hashes. Descriptions of now-retired assets in historical provenance do not mean those assets are shipped.

Gameplay inspiration does not grant permission to copy another game's characters, levels, recordings or trademarks. No commercial game asset packs, Hypit source, proprietary Codex runtime, user-uploaded video or user task recordings are intentionally redistributed. New contributions must include a usable license and provenance; unknown provenance blocks acceptance.
