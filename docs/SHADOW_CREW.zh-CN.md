# 影子施工队 / Shadow Crew

2026-09-20。三关原创纸艺投影解谜小样，手动选择试玩，暂不进入默认随机池。

## 试玩与目标

启动项目已有开发服务，打开 `/codex-stage?game=shadow-crew`。不需要购买硬件或下载新的软件。

你不直接控制工人，而是移动桌上的物件、改变投影大小，让墙上的影子接成道路。工人从左侧出发，真正站到右侧门前才算过关。没有自动通关动画，也不把游戏进度当作 Agent 进度。

1. **长一点，再长一点**：一把短尺、一盏灯。改变投影大小与位置，让影子跨过空隙。
2. **借来的桥**：一把尺不能同时覆盖两段路。工人抵达中转台会自动停步，可以把后方的桥借到前方；失败从中转台重试。
3. **一件物品，两条路**：两盏灯产生不同方向的投影；直尺、梳子与可开合剪刀分别形成平桥、阶梯和斜面。三种物件都有经过合法操作验证的路线，不要求唯一解。

## 操作

- 拖动下方桌面上的物件，改变投影的位置与高度；拖动灯距滑杆，改变投影大小。
- 按「出发」让工人行走，再按「停步」暂停横向移动。拖动物件也会停步，但不取消重力，挪走承重的影子仍会掉落。
- 第三关点击右下方的物件图标切换直尺、梳子和剪刀。剪刀上方圆形把手可左右拖动，改变开合角。
- 方向键微调物件，`-` / `=` 调整投影大小，`1` / `2` / `3` 选择物件，`Q` / `E` 开合剪刀；空格或回车出发 / 停步。
- `B` 撤销上一次布置，最多保留 12 步；不倒转工人或时间。会把工人埋进影子的布置或撤销会被拒绝。
- `R` 回安全台重试，保留已经完成的布置。`Escape` 取消尚未完成的拖拽。
- 默认静音，可通过现有声音按钮开启。支持触屏、减少动效、键盘操作描述和展开画面；手机上建议横屏或展开，物件更容易点中。

## 规则实现

- 使用项目现有 Matter.js，120 Hz 固定物理步。所有影子都由同一组投影顶点生成绘制轮廓和凸多边形碰撞体。
- 平行投影面的点光源关系：`wall = lamp + (source - lamp) * zoom`。物件与墙面坐标保持一致，桌面只是压缩呈现的操控层，不宣称是完整光学模拟。
- 双灯分别生成可站立的彩色投影，碰撞区域取并集。这是游戏规则，不模拟真实多光源中影子会被另一盏灯照亮的现象。
- 工人自动行走、有重力、无跳跃。为了让梳齿可走，已有支撑时会自动跨上不超过 12 个逻辑像素的小台阶；这属于明确的步行辅助，不是路径瞬移或预定胜利。
- 物件的把手、尺刻度和纸张装饰不参与碰撞；墙上的完整轮廓参与碰撞。不存在远程素材、采样录音或商业游戏角色。
- 关卡不计时、不扣生命；失败来自真实掉落。编辑和点击不加分，到达终点才结算。

## 生命周期与隐私

沿用已有游戏宿主。任务结束时同步停止输入、物理调度和音效，再保存本地检查点；下次任务可恢复物件、投影、落脚点、速度、章节和撤销历史。未完成的拖拽会先取消，避免保存一半的操作。

检查点只接受有界数字、固定枚举和有限数组，远小于 8 KiB。未知字段丢弃，不包含提示词、工具输出、文件路径或任何任务原文。损坏、非有限数、越界及不一致的结果状态会回退到关卡初始状态。Matter 接触缓存不保存，因此不承诺浮点逐位复现。

## 代码与验证

- `apps/codex-stage/studio/shadow-crew.js`：规则、投影、物理、输入及存档。
- `studio/shadow-painter.js`：原创纸艺场景、高 DPI Canvas、资源加载和降级。
- `studio/shadow-sound.js`：脚步、物件落位、过关、掉落等本地合成音效。
- `studio/shadow-catalog.js`：章节、操作描述和手动试玩入口。
- `apps/codex-stage/shadow.test.js`：三关路线、替代物件、真实掉落、撤销、坏存档、停止、恢复和包权限。
- `tools/test-shadow-browser.mjs`：真实鼠标拖动、剪刀把手、触屏拖动、三关通关、静音、减少动效、素材缺失降级、页面重载和移动布局。
- `tools/test-studio-browser.mjs`：所有游戏及模拟 Codex Dock 回归；不等同于已经在本机原生 Codex 中重新安装验证。

```bash
node tools/build-studio-assets.mjs
node tools/build-game-packs.mjs
node --test apps/codex-stage/shadow.test.js
npm run test:shadow-browser
```

浏览器脚本支持 `PLAYWRIGHT_MODULE`、`CHROME_PATH` 和 `STAGE_ORIGIN`。可用 `GAME_ID=shadow-crew` 运行 `tools/build-studio-previews.mjs` 更新真实游戏封面。

背景由内置 OpenAI imagegen 生成，运行时人物、工具、建筑与影子均为本项目绘制。完整提示词、转换方式、许可证边界见 `apps/codex-stage/assets/studio/ARTWORK.md`，摘要见 `art-manifest.json`。
