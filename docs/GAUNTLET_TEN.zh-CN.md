# 险境十局

本批为 0.9.0 源码更新。旧 26 款按用户要求退役，删除专属实现、素材、构建包和只服务它们的测试工具；公共物理、音效、Canvas 和输入组件继续保留。退役 ID 记录在 `retired-games.json`，构建器会清理过期包，防止下次打包复活。

**74 款保留作品 + 10 款新作 = 84 款**，其中统一游戏库 79 款、独立试玩 5 款。默认和精选都使用保留的 7 款已获正向反馈作品；新十款为手动试玩，不擅自视为用户已认可的正式作品。

入口：`/codex-stage?collection=gauntlet-ten&game=needle-rush`。

| 游戏 | 操作与挑战 | 三关变化 |
| --- | --- | --- |
| 针尖过山车 | 点击送线头，预测移动针眼的到达位置 | 针眼容差 23 / 17 / 12 像素；4 / 5 / 6 次连穿 |
| 楼顶钢丝社 | 按住左倾、松开右倾，控制惯性和阵风 | 12 / 15 / 18 秒；可容忍倾角缩小 |
| 偷一束月光 | 点击镜片改变折射方向，避开干扰镜 | 更多转折、干扰镜片与有限次数 |
| 死角搬运工 | 点击相邻地块，箱子只能推不能拉 | 1 / 2 / 3 个箱子；死角立即失败 |

失败可立即重试当前关卡，已经通过的关卡不必重来。任务结束会停止输入、计时、绘制与音效，恢复时从当前关卡的准备态重新开始，不在玩家没准备好时继续危险动作。

## 实现与素材

- 每款独立世界逻辑和绘制器，复用既有生命周期内核；不读取 Agent 内容，也不授予游戏网络或工具能力。
- 十幅原创本地 SVG 场景经 Chromium 渲染为 PNG，来源、大小和 SHA-256 见 `apps/codex-stage/gauntlet-ten/assets/provenance.json`。许可 Apache-2.0，不使用品牌角色或外部音频。
- 音效由本地 Web Audio 合成，默认静音；低动效保留判定所必需的移动，去掉装饰动效。
- 每包只嵌入自己的图片、玩法函数和绘制器，不装入其余九款世界逻辑。

## 验证

```bash
node tools/build-game-packs.mjs
node tools/build-playable-inventory.mjs
node --test apps/codex-stage/gauntlet-ten/*.test.mjs apps/codex-stage/retirement.test.js
node tools/test-gauntlet-ten-browser.mjs
node tools/test-gauntlet-dock.mjs
```

浏览器测试通过实际鼠标通关三关，另测触摸取消、移动窄屏、静音、低动效、无网络重启，以及任务结束后的画面冻结和零活动音源。Dock 测试使用模拟 Codex Shell，不等同于已经更新用户当前 Codex 安装。

报告目录：`output/gauntlet-ten-qa/`。本批没有重装 `~/.codex/agent-stage`、重启 Codex、发布 GitHub 或重建历史 DMG；那些副本与当前源码是不同的交付边界。
