# 运动与机关十连发

试玩入口：`/codex-stage?collection=sports-ten`。十款新游戏，每款三关，共三十关。沿用简单鼠标、触屏与键盘操作，不加入装备菜单、角色成长或多键组合。

## 十款玩法

| 游戏 | 主要操作 | 三关变化 |
| --- | --- | --- |
| 六袋台球 | 从白球向后拖，松开出杆 | 三、四、五颗彩球；八杆清台，白球落袋罚杆 |
| 楼顶投篮 | 从球向左下拉，松开投出 | 固定篮筐、移动篮筐、更高更快的移动篮筐；六投三中 |
| 弧线任意球 | 向后拉球，左右偏移产生内弯 | 两人墙、三人墙、更快门将；七脚进三球 |
| 草地网球 | 鼠标左右移动或触屏拖动接球 | 对手变快、球拍变窄；拍边击球可打斜线，先得三分 |
| 乒乓接杀 | 球靠近左侧球拍时轻点 | 四、五、六次回球，来球加快、球网增高；三次失误重来 |
| 保龄球连锁 | 向后拉球，松开滚出 | 两球击倒八、九、十瓶；球瓶会真实碰撞推倒彼此 |
| 冰壶擦线 | 按住蓄力、松手推壶，途中可按住扫冰 | 三壶累计四、五、六分；后两关增加护壶 |
| 多米诺过桥 | 按住移动桥，松开停桥并推牌 | 桥逐渐变窄；真实连锁必须通过缺口 |
| 叠盘杂技 | 左右移动托盘，让新盘落在盘堆中心 | 五、六、七只盘子，托盘和盘子变窄 |
| 回收压压乐 | 按住下压，松开抬起 | 六、七、八件，输送加快；误压电池立即停机，漏三件失败 |

这是单人短局街机化改编，不宣称实现国际比赛完整规则。台球是真实的白球撞彩球、库边反弹和六袋落球，不是上一批的宝石反弹清台。网球是平面球拍对抗，乒乓球是侧视过网接杀训练，二者规则、镜头和输入不同。

键盘：空格对应按住/松手或轻点；拖拽类按住空格后用方向键调整拉点，松开发射；网球与叠盘用左右键。开始/下一关/重试有独立按钮，开始操作不会同时消耗一次击球。

## 画面与物理

- 每款有独立的本地 PNG 环境、Canvas 物体画法和声音音高/音色；没有复制商业游戏资源。
- Matter 负责球、球拍、球瓶、盘子、机关和碎片的碰撞。篮筐只在球从上方下降穿过时计分，足球必须越过门线，乒乓球必须回到对面台面。
- 冰壶扫冰改变摩擦，不直接改变位置。盘堆与托盘接触时随支撑面运输，腾空盘子继续自由落体；这是短局的支撑辅助，不是刚体仿真精度承诺。
- 碰撞声、落袋声、入网声、陶瓷声和液压音全部使用本地 Web Audio 合成，默认静音，最多十二个并发声部。
- [素材来源、生成提示与许可](../apps/codex-stage/sports-ten/assets/ARTWORK.md)；`provenance.json` 记录源图、实际游戏封面、许可和文档的摘要。

## 生命周期与边界

- 任务开始时载入所选游戏；仍需玩家点开始，不会浪费球数。
- 任务完成立即取消动画帧、清理输入并停止声音。窗口失焦、触屏取消和暂停不会留下按住状态。
- 中断保存当前关号；下次恢复从本关准备状态开始，不保存半空中的球或半次挥拍。已过关/已通关存档恢复为静态结果，不重播成功声音。
- 新内容是源码 catalog 和 lazy Dock 的 **preview**。默认二十款随机池、八款精选池保持不变，先由用户试玩决定哪些纳入常用轮换。
- 自动化中的 Dock 验证使用模拟 Codex Shell，不冒充真机安装验证。本批不覆盖正在使用的 Codex companion，不修改主题，不生成或发布 DMG/GitHub Release。

## 开发与验证

```bash
node tools/build-game-packs.mjs
npm run test:sports
npm run test:sports-browser
node tools/test-sports-dock.mjs
node tools/build-sports-manifest.mjs
npm run test:ts
npm run test:py
```

浏览器脚本需要本地预览服务器，并读取 `STAGE_ORIGIN`（默认 `http://127.0.0.1:4180`）、`PLAYWRIGHT_MODULE`、`CHROME_PATH`。默认 Chrome 路径适用于 macOS；其他平台显式指定。原始回放不直接改坐标或分数：`tools/sports-replays.mjs` 只读快照，发送公开输入，台球和足球的练习规划在独立物理世界里计算。

源码目录 `apps/codex-stage/sports-ten/`：独立 world、独立 painter、catalog 和构建入口。复用上一批的生命周期、声音清理与输入适配；不把它当作任意社区代码沙箱。包按需加载，只包含自己的一张背景和相关代码，包体上限八 MiB。

验收证据写入 `output/sports-ten-qa/`：各关截图、窄屏截图、鼠标完成三关、触屏取消、离线重启、停止后画面/声音冻结，以及独立的 `dock-report.json`。生成测试报告不等于用户觉得好玩，是否正式保留仍看试玩反馈。
