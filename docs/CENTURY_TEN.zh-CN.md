# 百款新章：十种新挑战

试玩：`/codex-stage?collection=century-ten&game=ink-rail`。十款不同规则，每款三关。上一批偏反应、躲避和时机，这批增加画线创造、比例判断、有限步规划、图形辨伪和空间整理。难度逐关上升，所有限时关卡都有可见倒计时。

## 游戏与操作

| 游戏 / ID | 主要操作 | 递进挑战 | 美术方向 |
| --- | --- | --- | --- |
| 色彩炼金 `chromatic-lab` | 按住三个阀门之一注入原液，松开停止 | 两色到三色；目标比例容差从 ±8 到 ±3 个百分点 | 玻璃实验台 |
| 一圈打尽 `loop-lock` | 按住画闭合圈，捕获宝石 | 三圈收三枚到五枚；墨量减少，不能圈进黑色尖刺 | 珠宝镶嵌棋盘 |
| 一笔通车 `ink-rail` | 从左站向右画一条轨道，松开开车 | 一张到三张车票，悬石与墨量限制；漏票不能过关 | 木版画山谷 |
| 汽水层层消 `soda-strata` | 点击三个以上相连同色气泡 | 消除后重力下落、不补球；第三关七步清空 | 波普汽水海报 |
| 漏水别慌 `leak-patrol` | 按住漏水阀门维修，可以移动到另一处 | 六到十处，漏得更快、修得更慢；水满失败 | 手绘潜艇机舱 |
| 四分之一转 `quarter-turn` | 点击四个转轴之一，旋转邻近四块 | 有限次数内复原小样；转轴影响彼此 | 包豪斯陶片 |
| 印章风暴 `stamp-storm` | 红叉拒收、绿勾放行 | 与样本逐一比对；图形增多、时限收紧 | 套色印刷办公室 |
| 冰箱塞塞 `fridge-fit` | 拖动异形保鲜盒放进格子 | 四盒到六盒，方向固定、不重叠；错位可重拖 | 手工剪纸厨房 |
| 解结事务所 `knot-office` | 拖动彩色端点 | 五根到九根线，消除所有交叉；堆叠端点无效 | 刺绣布面 |
| 影子露馅 `shadow-tell` | 点击唯一与影子不一致的物品 | 四件到八件，比较柄的方向、齿数等；三次失误失败 | 灯箱展品 |

推荐先玩一笔通车、一圈打尽、漏水别慌。装箱、旋转和消除更偏思考，不适合的作品可以在首发筛选时移出默认阵容。

一笔通车的轨道要画在票下方一点，让车身经过票。可以画缓坡，不能向后绕或画特别陡的坡。下落与碰石都由实际物理判定，不按“画过线”直接判成功。

键盘：聚焦画布后方向键移动指向，空格按下 / 松开对应鼠标操作；画布下方圆箭头按钮重试。自由画线和拖动用鼠标、触屏更直接。每关结果后有短暂防误触，再次开始进入下一关或重试。

## 数量与边界

当前源码共有 **95 款 catalog 游戏 + 5 款独立试玩 = 100 款不同作品**。见[自动生成清单](PLAYABLE_INVENTORY.zh-CN.md)。三关不是三款，`return-fire` 和 `statue-act` 的独立页面也不会再计一次。

包含实验和待返工作品，不等于 100 款通过用户认可、真机验收的正式发行游戏。默认随机池仍是 20 款，精选池仍是 8 款，两者与 catalog 重合，不能相加。本批十款作为可手选 preview 加入，不偷偷扩充默认随机池。

已接入源码合集、按需 reviewed pack 和 lazy Dock。任务结束同步停止输入、模拟、绘制和声音。失焦、暂停和触控取消清除按住状态。只保存小型本地关卡检查点，未完成关卡恢复到准备态，完成关卡保持结果、不补播获胜音效。

本批不改 Codex.app、`~/.codex`、已安装 companion、旧 DMG 或用户主题；模拟 Dock 测试不能证明真实安装已经更新。未创建或发布 GitHub Release。

## 实现与素材

入口：`apps/codex-stage/century-ten/`。`worlds.js` 是规则、`painter.js` 是十套画面、`rules.js` 是局部几何和棋盘辅助、`catalog.js` 是游戏目录。复用现有生命周期和声音内核，每次仅加载选中游戏及其背景。

仅一笔通车带本地 MIT 许可 Matter.js；其余为离散规则，不额外加载物理引擎。三个原创生成背景保留提示词，七个原创 SVG 场景本地光栅化；动态物品均由规则驱动的 Canvas 绘制。没有商业游戏素材或外部音频，声音由本地振荡器合成。许可、原始提示词与 SHA-256 见 [ARTWORK.md](../apps/codex-stage/century-ten/assets/ARTWORK.md) 和 `assets/provenance.json`。生成素材不代表独占版权保证。

三个插画包上限 8 MiB，其他包上限 800 KB，lazy Dock 仍保持 50 KB 启动脚本上限。审查过的 JavaScript 包与声明式场景不同，不能把 Shadow DOM 当成不可信代码的安全沙箱。

## 验证与重建

```bash
node tools/build-century-art.mjs
node tools/build-game-packs.mjs
node tools/test-century-ten-browser.mjs
node tools/test-century-dock.mjs
node tools/build-century-manifest.mjs
node tools/build-playable-inventory.mjs
node --test apps/codex-stage/century-ten/*.test.mjs
npm test
```

浏览器工具需要 Playwright 与 Chrome，可配置 `PLAYWRIGHT_MODULE`、`CHROME_PATH`、`STAGE_ORIGIN`。本机默认端口为 4180；`CENTURY_GAME=<id>` 单款补测另写报告，不覆盖完整合集报告。背景素材已随源码提供，玩家不需要生成工具。

规则测试覆盖每款三关的合法输入通关、不操作失败、错误策略失败、取消、检查点、瞬时停止、无效坐标、素材摘要、包隔离和声音释放。调色和维修所需的“按住并移动”新增了窄范围输入支持，并测试旧式无位置长按仍不接收移动。

浏览器脚本通过真实鼠标事件通关三十关，不修改游戏状态；另做 390px 触屏、取消、减少动效、像素非空、停止后画面冻结、静音与离线恢复检查。移动端是交互冒烟测试，不宣称三十关全部触屏通关。新十款与上一批十款还做模拟 Codex Shell 的任务生命周期、键盘、清理及主题节点保留回归。

报告和截图在 `output/century-ten-qa/`，不应携带个人输出发布。自动通关只证明可完成；乐趣、难度与保留名单仍由实际试玩决定。
