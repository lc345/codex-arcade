# 抓到算你的 / Grab & Go

类似黄金矿工的单键时机玩法，使用原创抓宝机、物品和音效。目标不是走位或管理背包，而是看准方向，抓住值得花时间带回来的宝物。

## 试玩

本机现有预览服务：[打开游戏](http://127.0.0.1:4180/apps/codex-stage/grab-go/index.html)。

其他开发者可以用项目现有服务器：

```sh
PORT=4180 npm run serve:lab
```

打开 `/apps/codex-stage/grab-go/index.html`。不需要安装新的游戏引擎，运行时图片、图标、物理库均来自本地；首次加载完成后可断网游玩。

- 点击“开抓”，随后点击画面、点击“下钩”或按空格发射；抓取和回收自动完成。
- 夹爪自动摆动，只有空闲时能再次发射；连点不会增加钩子。
- 金块、钻石、旧掌机、机器人价值不同。石头和废铁收益低、回收慢，容易耗尽时间。
- 闹钟成功收回后增加 6 秒；只碰到不算到账。
- 第三柜有横移挡板和会移动的发条车；挡板会让空钩提前返回。
- 超时前已经抓住的物品允许最后一次收回，空钩不延长本关。
- 默认静音，左下角扬声器开关可启用原创绞盘、抓取和到账音效。
- Esc 暂停；切到其他窗口或隐藏页面也暂停，不会偷偷耗掉时间。

| 关卡 | 时间 | 目标 | 变化 |
| --- | --- | --- | --- |
| 街角初开张 | 42 秒 | 600 | 熟悉摆动、重量和收益 |
| 大件有大价 | 44 秒 | 900 | 高价大件与重物交错 |
| 宝贝会溜走 | 46 秒 | 1100 | 移动奖品与横移挡板 |

## 实现与边界

Canvas 2D 绘制原创位图和机械夹爪，项目已有的 Matter.js 以 120 Hz 更新物理。抓住时创建真实绳索约束，物品跟随回收并晃动；积分只能在回到收集口后获得。碰撞检测、重量影响回收速度、时间、结算来自同一个规则模块，不用动画推测成功。

桌面使用宽版柜体；窄屏初次进入时采用紧凑排布，调整摆角、物品间距和挡板，同时保持真实碰撞。素材不会简单地被横向压扁。减少动效模式关闭装饰粒子，不改变核心游戏反馈。

“结束任务”立即冻结画面、物理和声音，停止 RAF，并保存有界本地检查点。刷新或下次开始后，必须点击继续才会恢复；已经抓住的物品和分数保留。触屏取消、拖动、键盘重复按下及异步素材加载完成均不能绕过停止状态。

这是**独立生命周期模拟器**，未接入真实 Codex hooks、随机池、精选集或已安装 Dock。旧游戏、安装包、用户主题和 Codex 配置没有变化。源码接入和实际安装更新应作为后续独立步骤验收。

## 文件与素材

- `apps/codex-stage/grab-go/world.js`：三柜布局、碰撞、绳索、收益和存档。
- `painter.js`：高 DPI Canvas、透明图集、横竖版绘制。
- `sound.js`：Web Audio 合成音效，默认静音，可立即停止。
- `app.js`：输入、生命周期、焦点暂停和界面。
- `assets/cabinet.png` 与 `assets/treasures.png`：两张原创生成图片，共 4,378,395 字节，约 4.18 MiB。
- [完整提示词与素材来源](../apps/codex-stage/grab-go/assets/ARTWORK.md)。PNG 原文件保留不变，图集仅在绘制时根据透明边界裁切。
- [资源摘要](../apps/codex-stage/grab-go/assets/provenance.json)记录尺寸、字节数、SHA-256 和提示词摘要。

项目原创代码与素材按 Apache-2.0 分发，不主张 AI 生成内容的独占版权；没有使用黄金矿工或其他商业游戏的图片、音乐、名称标识。工具栏复用已有 Lucide 图标及其 ISC 许可证。

## 验证

2026-10-02 验证结果：本游戏 15 项单元测试、完整 JS/TS 500 项和 Python 9 项全部通过。最终浏览器鼠标通关三柜收益分别为 680、1085、1445；浏览器错误为 0。触屏取消、键盘工具栏、暂停恢复不误发射、停止后像素不变及无声、存档恢复、离线和延迟加载检查均通过。

```sh
npm run test:grab
npm run test:grab-browser
npm run test:ts
npm run test:py
```

浏览器测试使用 Playwright 和已安装 Chrome；也可设置 `PLAYWRIGHT_MODULE`、`CHROME_PATH`、`STAGE_ORIGIN`。报告位于 `output/grab-qa/report.json`，桌面、竖屏、抓取中和通关截图在同目录。

规则测试覆盖实际抓取后才得分、空钩、轻重差异、失败重试、立即停止、半途回收存档、闹钟、防御性读取、移动奖品、挡板和横竖版三关通关。资源测试校验许可、提示词、图片尺寸与内容摘要；声音测试检查静音、停止和销毁。

浏览器测试只读局面并使用正常鼠标点击完成三关，没有直接改分数或传送物品；另查实际触屏、空格与工具栏键盘输入、取消手势、停机前后像素一致、离线、恢复和延迟加载。这证明流程能通，但难度与乐趣仍以真人试玩反馈为准。
